iOS integration guides for **PayPal Mobile SDK V3.0.0**.

New to this SDK? Start here, in order:

1. [Concepts & Responsibilities](concepts-and-responsibilities.md) — how a V3 integration fits together and who's responsible for what
2. [Which Guide Do I Use?](which-guide-do-i-use.md) — find the right guide for what you're building
3. [Install & Setup](install-and-setup.md) — add the SDK, `CoreConfig`, register return links (do this first)

Upgrading an existing 2.x integration? See [Migrate V2 → V3](migrate-v2-to-v3.md).

Once setup is done, integrate a payment method:

* [PayPal Checkout — Integration Guide](paypal-checkout.md) — One-Time Checkout, Vault (with/without purchase), Pay Later / PayPal Credit
* [Payment Buttons](payment-buttons.md) — add and customize the PayPal button family
* [Venmo Checkout — Integration Guide](venmo-checkout.md) — One-Time Checkout
* [Card / ACDC — Integration Guide](card-acdc.md) — card payments and vaulting

Having trouble? See [Troubleshooting](troubleshooting.md).
